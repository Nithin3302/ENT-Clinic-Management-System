# ENT Clinic Management System Prototype

A simple web prototype for the ENT Clinic Management System covering:

- Module 1: Patient Management
- Module 2: Appointment Management
- Module 3: OPD Consultation
- Module 4: ENT Examination
- Module 5: Phonosurgery
- Module 6: Balance Disorder
- Module 7: Audiology

## How to use

1. Open `index.html` in a browser.
2. Use the top menu to switch between modules.
3. Enter data in each form and click `Save`.
4. Saved records are stored in browser `localStorage`.

## Files

- `index.html` — main UI and form layout
- `styles.css` — styling and layout
- `script.js` — form handling, data storage, and rendering

## Notes

This prototype is intended as a starting point for the assignment. You can extend it by adding:

- backend database (SQLite / MySQL / Firebase)
- authentication / role-based access
- reporting and billing modules
- teleconsultation workflow
